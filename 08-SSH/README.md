# SSH

[svg](https://github.com/Max-Nowak-1/rhel-homelab/blob/main/08-SSH/README.md#ssh)

This section documents my hands-on RHCSA SSH and remote file transfer labs completed on Red Hat Enterprise Linux 10.

## Topics Covered

[svg](https://github.com/Max-Nowak-1/rhel-homelab/blob/main/08-SSH/README.md#topics-covered)

* Configuring and managing the OpenSSH service
* Connecting to remote systems with `ssh`
* Managing SSH users and authentication
* Configuring SSH server settings with `sshd_config`
* Testing the `PermitRootLogin` directive
* Restarting and reloading the SSH service after configuration changes
* Using public key authentication with `ssh-keygen`
* Transferring files with SFTP
* Downloading remote files with `get`
* Uploading files with `put`
* Using `lcd` to change the local working directory
* Using `lput` and `lget` for local file transfers through an SFTP session
* Troubleshooting SSH authentication and access
