# Linux Firewall

This section documents my hands-on RHCSA firewall administration labs completed on Red Hat Enterprise Linux 10.

## Topics Covered

* Managing the `firewalld` service
* Working with firewall zones
* Adding and removing firewalld services
* Adding individual ports and port ranges
* Configuring runtime firewall rules
* Configuring permanent firewall rules
* Reloading firewalld to activate permanent configuration changes
* Verifying firewall configuration with `firewall-cmd`
* Verifying persistent firewall rules through zone XML configuration files
* Testing firewall rule persistence across system reboots
